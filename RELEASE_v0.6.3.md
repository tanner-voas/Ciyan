# Cíyán v0.6.3

Stats-only UI improvements: compact wrapping character and grammar feedback, due projection with adjustable time window and resolution, horizontal scroll and inspectable bucket counts, spacing and table readability.

Master dictionary: 11893 vocabulary cards and 3444 grammar contexts (20 additional curated contexts on top of the 663-entry post-v0.6.2 expansion).

Restoring full backups preserves newer current/master vocabulary and grammar entries, while loading backup learning records and settings. Original word IDs are retained so schedules and history remain attached. This is distinct from clearing data.

Mock backup is supplied separately and is NOT in this repository or dist.
