# Ciyan v0.9.19 — reader assistance and translation

Seven aid levels (none, underline, word spacing, struggle pinyin, struggle pinyin and English, all pinyin, all pinyin and English). Strict score threshold 0–3, default 1.5, step 0.1. Reader readiness additionally uses persisted qualifying Reader practice from the last 24 hours, including practice-only grades without changing SRS scores. The master dictionary and each novel's term scores remain shared across editions. Bookmarks and completion are edition-scoped; legacy shared state is attributed to the last selected edition only. Canonical Chinese is used for speech and translations, not annotation DOM text.

Paragraph translation is opt-in and requested explicitly. PWA-Core provides a seven-day local cache and a private Cloudflare Worker with a shared monthly character cap. Existing Google profile session authorization is required for uncached requests.

**Before public use:** download Google's official attribution graphics from https://docs.cloud.google.com/translate/attribution (direct zip: https://docs.cloud.google.com/static/translate/images/google-translate-attribution.zip), select the unmodified color “powered by Google Translate” PNG, and save it as `icons/google-translate-attribution.png` in this repository. Commit it and restore `enforceTranslationAttribution=true` in `reader-ui.js`. Enforcement is temporarily disabled for private testing while the asset is unavailable. The UI still attempts to display the official graphic and falls back to linked text if missing; this fallback does not replace the official attribution requirement. This asset could not be retrieved in the preparation environment. See PWA-Core's `TRANSLATION_SETUP.md`. No key goes in any repo. Translation is an external service; requested paragraph text is sent to Google.
