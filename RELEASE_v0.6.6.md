# Cíyán v0.6.6 — durable content + verified fonts

**Based on the committed v0.6.5 repository.** No graded-reader mode or new dictionary expansion was introduced.

## 1. Persistent content reconciliation

The startup path previously called `replaceMaster(state, MASTER)` unconditionally.
This could discard restored/custom vocabulary and grammar whenever the PWA reopened.

v0.6.6 uses `reconcileBundledMaster` when entering a new bundled app version:
- Existing vocabulary is preserved by headword, with its original ID, definition, tags, synonyms, schedules, and history.
- Existing grammar entries are preserved by exact marked-up sentence, with their original ID and review records.
- Newly bundled entries are added only if missing. ID collisions receive new stable IDs without destroying local records.
- Successful reconciliation is saved atomically in the IndexedDB content/progress store before study begins.
- A `bundledMasterVersion` marker means manually importing a complete master file is no longer silently replaced by bundled data on every reload.
- Importing a full backup still merges the restored collection with the app's current and default content as before.

The user's supplied HSK4 mock backup was parsed and reconciled: 11,893 vocabulary cards, 3,469 grammar entries, 23,527 word reviews and 792 grammar reviews were retained; the sample schedule was identical after a full backup round trip.

## 2. Fonts from the screenshots

The *installed-font* selection is now:

| Difficulty | Options | Mixed |
|---|---|---|
| Beginner | iPhone default (PingFang) | Not offered |
| Intermediate | 站酷小薇 LOGO 体 (ZCOOL XiaoWei), 站酷快乐体 (ZCOOL KuaiLe) | Both |
| Advanced | 杨任东竹石体, 马善政毛笔楷书 (Ma Shan Zheng) | Both |
| Expert | 沐瑶软笔手写体, 志莽行书 (Zhi Mang Xing) | Both |

**Font files are not included.** The user installs them separately; some iOS
installers and Safari versions do not expose those fonts to webpages. The app
must receive a successful `FontFace.load()` result before saving a font choice.
Missing fonts produce an in-app error dialog, and the last accepted font stays
selected. Mixed validates both families, so partial installations are rejected.
An unavailable font loaded from a previous backup is reset to Beginner with an
explicit dialog. The default clean print style is always available.

For trustworthy font sources, prefer the Google Fonts OFL distributions of
ZCOOL XiaoWei, ZCOOL KuaiLe, Ma Shan Zheng, and Zhi Mang Xing. For 杨任东竹石体
and 沐瑶软笔手写体, use the respective author/foundry distribution and check its
installation and reuse terms. The displayed *CSS family name* may vary by
font package; the app probes Chinese and English aliases.

## 3. Mixed-mode performance

Previously the renderer created a `span` element around **every Chinese
character** on each page render. This was particularly expensive with long
lists and would be untenable for a graded reader.

The new `mixed-fonts.css` is generated by `node build_mixed_fonts.mjs` and
assigns CJK codepoints to the two fonts in each difficulty through CSS
`unicode-range`. There is **no runtime per-character DOM mutation**. Character
assignment is deterministic for a codepoint, so a repeated Hanzi uses the same
font wherever it appears. The generated CSS is 405 KB uncompressed and is
included in the PWA offline cache. It contains font family references, **not**
font binary files, and compresses well in the deployment ZIP.

## Verification

Run `npm test` for the full automated suite, `node build_mixed_fonts.mjs` to
regenerate the mixed-style CSS, and `python3 package.py` for the Cloudflare
Pages folder `dist/ciyan`.

iPhone Safari font availability and real-device visual consistency cannot be
verified in this environment. If font loading remains unavailable despite
installation, keep Beginner rather than relying on a misleading fallback.
